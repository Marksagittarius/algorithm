# 0x03 滑动窗口

## 引言

滑动窗口本质上是一种丝滑的双指针技巧的应用方式，能够高效地解决数组上的区间「蠕动」问题。

滑动窗口的「蠕动」方式需要读者在例题中进行感受。

## 例题

[209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/description/)

```c++
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        int ans = n + 1;
        int l = 0;
        int sum = 0;
        for (int r = 0; r < n; r++) {
            sum += nums[r];
            while (sum >= target) {
                ans = min(ans, r - l + 1);
                sum -= nums[l++];
            }
        }
        return ans == n + 1 ? 0 : ans;
    }
};
```

[3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/)

```c++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n = s.size();
        int ans = 0;
        int l = 0;
        int cnt = 0;
        vector<int> mp(128, 0);
        for (int r = 0; r < n; r++) {
            if (++mp[s[r]] > 1) cnt++;
            while (cnt != 0) {
                if (--mp[s[l]] == 1) {
                    cnt--;
                }
                l++;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

值得注意的是，在维护本题的区间性质时并不需要逐次统计当前区间内的字符种类及其数量，只需使用数组 `mp` 与计数器 `cnt` 动态维护即可，该技巧在后续题目中仍有可能出现。

[76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/description/) 一题恰好运用了上一题中出现的技巧：

```c++
class Solution {
public:
    string minWindow(string s, string t) {
        string ans = "";
        int n = s.size();
        int m = t.size();
        int ll = -1, rr = n;
        vector<int> wc(128, 0);
        vector<int> cw(128, 0);
        for (auto& ch : t) wc[ch]++;
        int l = 0;
        int cnt = 0;
        for (int r = 0; r < n; r++) {
            if (++cw[s[r]] <= wc[s[r]]) cnt++;
            while (cnt == m) {
                if (r - l < rr - ll) {
                    rr = r;
                    ll = l;
                }
                if (--cw[s[l]] < wc[s[l]]) cnt--;
                l++;
            }
        }
        if (ll >= 0 && rr < n)
            return s.substr(ll, rr - ll + 1);
        return "";
    }
};
```

[438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/)

```c++
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> ans;
        int n = s.size();
        int m = p.size();
        if (m > n) return ans;
        vector<int> wc(128, 0);
        vector<int> cw(128, 0);
        int cnt = 0;
        for (auto ch: p) wc[ch]++;
        int l = 0; 
        for (int r = 0; r < n; r++) {
            if (++cw[s[r]] <= wc[s[r]]) cnt++;
            while (cnt == m) {
                if (r - l + 1 == m) ans.push_back(l);
                if (--cw[s[l]] < wc[s[l]]) cnt--;
                l++;
            }
        }
        return ans;
    }
};
```

与此同时，通过观察不难发现，在解决滑动窗口相关问题时困扰解题者的往往并非窗口蠕动的方式，而是动态更新并维护其区间性质的手段。

例如，在[30. 串联所有单词的子串](https://leetcode.cn/problems/substring-with-concatenation-of-all-words/description/) 一题中，如果像上述两题一样采用以单个字母为单位进行更新的策略，会极大地增加检验区间满足题设条件与否的时间成本。好在，`words` 中所有单词的长度恰好一致，可以一次性蠕动右侧指针 `m` 次以动态维护区间性质：

```c++
class Solution {
public:
    vector<int> findSubstring(string s, vector<string>& words) {
        vector<int> ans;
        int n = s.size();
        int len = words.size();
        int m = words[0].size();
        unordered_map<string, int> wc;
        for (auto& wd : words) wc[wd]++;
        for (int i = 0; i < m; i++) {
            int l = i;
            int cnt = 0;
            unordered_map<string, int> cw;
            for (int r = i; r < n; r += m) {
                string str = s.substr(r, m);
                if (wc.count(str) && ++cw[str] <= wc[str])
                    cnt++;
                while (cnt == len) {
                    if (r - l == (len - 1) * m) {
                        ans.push_back(l);
                    }
                    string rts = s.substr(l, m);
                    if (wc.count(rts) && --cw[rts] < wc[rts])
                        cnt--;
                    l += m;
                }
            }
        }
        return ans;
    }
};
```
