# 0x06 字符串

## 引言

字符串可以被认为是由字符构成的数组，然而，在实际的考查中，字符串往往被赋予其独特的意义，由此诞生了诸多面向字符串问题的精妙算法。

在字符串问题的考查中，回文串的考查始终为重中之重。

## 回文串问题

[647. 回文子串](https://leetcode.cn/problems/palindromic-substrings/description/) 可使用一种较为粗暴的方式解决：

```c++
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size();
        int ans = 0;
        for (int i = 0; i < 2 * n - 1; i++) {
            int l = i / 2;
            int r = i / 2 + i % 2;
            while (l >= 0 && r < n && s[l] == s[r]) {
                l--;
                r++;
                ans++;
            }
        }
        return ans;
    }
};
```

该问题存在一个更为高效的算法，其名为 Manacher 算法：

```c++
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size();
        int ans = 0;
        string str = "$#";
        for (auto& ch : s) {
            str += ch;
            str += '#';
        }
        n = str.size();
        str += '!';

        vector<int> f(n);
        int l = 0, r = 0;
        for (int i = 1; i < n; i++) {
            f[i] = i <= r ? min(r - i + 1, f[2 * l - i]) : 1;
            while (str[i + f[i]] == str[i - f[i]])
                f[i]++;
            if (i + f[i] - 1 > r) {
                l = i;
                r = i + f[i] - 1;
            }
            ans += f[i] / 2;
        }
        return ans;
    }
};
```

该算法通过维护回文中心和最大回文半径，显著提高了枚举的效率。

## 字符串哈希

字符串可以被看作是一种进制数。

[214. 最短回文串](https://leetcode.cn/problems/shortest-palindrome/description/)

```c++
class Solution {
public:
    string shortestPalindrome(string s) {
        int n = s.size();
        long long base = 131, mod = 1e9 + 7;
        long long l = 0, r = 0, m = 1;
        int ans = -1;
        for (int i = 0; i < n; i++) {
            l = (l * base + s[i]) % mod;
            r = (r + m * s[i]) % mod;
            if (l == r) ans = i;
            m = m * base % mod;
        }
        string str = ans == n - 1 ? "" : s.substr(ans + 1, n);
        reverse(str.begin(), str.end());
        return str + s;
    }
};
```

## KMP

KMP 是一种高效的字符串匹配算法，其一般构造过程如下：

```c++
vector<int> prefix(string s) {
    int n = s.length();
    vector<int> next(n);
    for (int i = 1; i < n; i++) {
        int j = next[i - 1];
        while (j > 0 && s[i] != s[j]) j = next[j - 1];
        if (s[i] == s[j]) j++;
        next[i] = j;
    }
    return next;
}
```

`next` 数组存储的是当前子串中，最长的相同前缀和后缀的长度。

```c++
void kmpSearch(string s, string p) {
    int n = s.size(), m = p.size();
    vector<int> next = prefix(p);
    
    for (int i = 0, j = 0; i < n; i++) {
        while (j > 0 && s[i] != p[j]) {
            j = next[j - 1];
        }
        if (s[i] == p[j]) {
            j++;
        }
        if (j == m) {
            cout << "Pattern found at index " << i - m + 1 << endl;
            j = next[j - 1];
        }
    }
}
```

基于 `next` 数组可以统计所有前缀在字符串中出现的次数：

```c++
vector<int> ans(n + 1);
for (int i = 0; i < n; i++) ans[next[i]]++;
for (int i = n - 1; i > 0; i--) ans[next[i - 1]] += ans[i];
for (int i = 0; i <= n; i++) ans[i]++;
```

[459. 重复的子字符串](https://leetcode.cn/problems/repeated-substring-pattern/description/)

```c++
class Solution {
public:
    bool repeatedSubstringPattern(string s) {
        return (s + s).find(s, 1) != s.size();
    }
};
```
