# 0x05 差分数组

## 引言

差分是前缀和的逆过程，差分数组能够高效地解决在数组某连续区间上批量增减相同数值的操作，其一般构造过程如下：

```cpp
int nums[LEN];
int diff[LEN];
int pre[LEN];

for (int i = 1; i <= n; i++)
    scanf("%d", &nums[i]);

for (int i = 1; i <= n; i++)
    diff[i] = nums[i] - nums[i - 1];

for (int i = 1; i <= n; i++)
    pre[i] = pre[i - 1] + diff[i];
```

其中 `diff` 数组是 `nums` 数组的差分数组，通过前缀和构造 `pre` 数组即可将其还原。

`nums[i, j] += 3` 等价于 `diff[i] += 3, diff[j + 1] -= 3`。

## 例题

[1109. 航班预订统计](https://leetcode.cn/problems/corporate-flight-bookings/description/)

```c++
class Solution {
public:
    vector<int> corpFlightBookings(vector<vector<int>>& bookings, int n) {
        vector<int> nums(n);
        for (auto& booking : bookings) {
            nums[booking[0] - 1] += booking[2];
            if (booking[1] < n) {
                nums[booking[1]] -= booking[2];
            }
        }
        for (int i = 1; i < n; i++) {
            nums[i] += nums[i - 1];
        }
        return nums;
    }
};
```

[1094. 拼车](https://leetcode.cn/problems/car-pooling/description/)

```c++
class Solution {
public:
    bool carPooling(vector<vector<int>>& trips, int capacity) {
        int len = 0;
        for (const auto& trip: trips) {
            len = max(len, trip[2]);
        }

        vector<int> diff(len + 1);
        for (const auto& trip: trips) {
            diff[trip[1]] += trip[0];
            diff[trip[2]] -= trip[0];
        }

        int cnt = 0;
        for (int i = 0; i <= len; ++i) {
            cnt += diff[i];
            if (cnt > capacity) {
                return false;
            }
        }
        return true;
    }
};
```
