# 0x02 二分

## 引言

二分体现了「分而治之」的思想，常见的二分技巧有「二分答案」与「二分查找」两种。

## 二分答案

将数组划分为两个连续区间，若其中一个区间中的所有元素均满足某种性质而另一区间中的所有元素均不满足，即可使用二分答案技巧找到两个区间分界之端点。

逼近右半区间的左端点：

```cpp
while (l < r) {
    int mid = (l + r) / 2;
    if (check(mid))
        r = mid;
    else
        l = mid + 1;
}

return l;
```

逼近左半区间的右端点：

```cpp
while (l < r) {
    int mid = (l + r + 1) / 2;
    if (check(mid))
        l = mid;
    else
        r = mid - 1;
}

return r;
```

### 例题

[69. x 的平方根](https://leetcode.cn/problems/sqrtx/description/) 一题中，基于二分答案构造 `sqrt(x)`:

```c++
class Solution {
public:
    int mySqrt(int x) {
        long long l = 0;
        long long r = x;
        while (l < r) {
            long long mid = (l + r + 1) / 2;
            if (mid * mid <= (long long)x)
                l = mid;
            else
                r = mid - 1;
        }
        return r;
    }
};
```

[29. 两数相除](https://leetcode.cn/problems/divide-two-integers/description/) 仅使用加减法和位运算即可构造整数除法，不可谓不巧妙：

```c++
class Solution {
public:
    long mul(long a, long b) {
        long ans = 0;
        while (a > 0) {
            if (a & 1) ans += b;
            b = b << 1;
            a = a >> 1;
        }
        return ans;
    }

    int divide(int a, int b) {
        if (a == 0) return 0;
        bool sign = a > 0 && b > 0 || a < 0 && b < 0;
        long x = abs((long)a);
        long y = abs((long)b);
        long l = 0, r = x;
        while (l < r) {
            long mid = (l + r + 1) / 2;
            if (mul(y, mid) <= x) l = mid; else r = mid - 1;
        }
        if (sign && r > (long)(INT_MAX)) return INT_MAX;
        if (!sign && -r < (long)(INT_MIN)) return INT_MIN;
        return sign ? r : -r;
    }
};
```

在 `c++` 中常使用 `lower_bound` 函数来进行二分：

```c++
std::lower_bound(a, a + n, val);
std::upper_bound(a, a + n, val);
std::lower_bound(a, a + n, val, less<T>());
std::upper_bound(a, a + n, val, less<T>());
std::lower_bound(a, a + n, val, greater<T>());
std::upper_bound(a, a + n, val, greater<T>());
```

[34. 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/description/)

```c++
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        auto lhs = lower_bound(nums.begin(), nums.end(), target);
        auto rhs = upper_bound(nums.begin(), nums.end(), target);
        if (lhs == nums.end()) return {-1, -1};
        int l = lhs - nums.begin();
        int r = rhs - nums.begin() - 1;
        if (nums[l] != target) return {-1, -1};
        return {l, r};
    }
};
```

当然该题目也可以不使用标准库函数进行解答：

```c++
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int lhs = -1, rhs = -1;    
        int n = nums.size();
        int l = 0, r = n - 1;   
        while (l < r) {
            int mid = (l + r) / 2;
            if (nums[mid] >= target)
                r = mid;
            else
                l = mid + 1;
        }
        lhs = l;
        l = 0, r = n - 1;
        while (l < r) {
            int mid = (l + r + 1) / 2;
            if (nums[mid] <= target)
                l = mid;
            else
                r = mid - 1;
        }
        rhs = r;
        if (lhs < 0 || rhs < 0 || lhs >= n || rhs >= n)
            return {-1, -1};
        if (nums[lhs] != target || nums[rhs] != target)
            return {-1, -1};
        return {lhs, rhs};
    }
};
```

[719. 找出第 K 小的数对距离](https://leetcode.cn/problems/find-k-th-smallest-pair-distance/description/) 不仅需要二分答案，也需要在使用 `upper_bound` 函数统计数对个数：

```c++
class Solution {
public:
    bool f(vector<int>& nums, int k, int mid) {
        int n = nums.size();
        int cnt = 0;
        for (int i = 0; i < n - 1; i++) {
            auto it = upper_bound(nums.begin() + i + 1, nums.end(), nums[i] + mid);
            cnt += it - nums.begin() - i - 1;
            if (cnt >= k) return true;
        }
        return cnt >= k;
    }

    int smallestDistancePair(vector<int>& nums, int k) {
        int n = nums.size();
        sort(nums.begin(), nums.end());
        int l = 0, r = nums[n - 1];
        while (l < r) {
            int mid = (l + r) / 2;
            if (f(nums, k, mid)) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }
        return l;
    }
};
```

## 二分查找

二分查找能够在有序数组中以指数时间复杂度找到某个元素：

```c++
int l = 0, r = n - 1;

while (l <= r) {
    int mid = (l + r) / 2;
    if (q[mid] > k)
        r = mid - 1;
    else if (q[mid] < k)
        l = mid + 1;
    else
        return mid;
}

return -1;
```

诚然，在常见的算法题目中不会有如此清晰的二分查找场景，例如在 [33. 搜索旋转排序数组](https://leetcode.cn/problems/search-in-rotated-sorted-array/description/) 一题中，数组被不怀好意者从中间割裂开：

```c++
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int n = nums.size();
        int l = 0, r = n - 1;
        while (l <= r) {
            int mid = (r + l) / 2;
            if (nums[mid] == target) return mid;
            if (nums[0] <= nums[mid]) {
                if (nums[0] <= target && target <= nums[mid])
                    r = mid - 1;
                else 
                    l = mid + 1;
            } else {
                if (nums[mid] <= target && target <= nums[n - 1])
                    l = mid + 1;
                else
                    r = mid - 1;
            }
        }
        return -1;
    }
};
```

欲解决此问题需要首先判断当前 `mid` 是否位于数组的左侧（割裂前的右侧），即是否满足 `nums[mid] >= nums[0]`;

若 `mid` 位于左侧，需要判断是否有 `nums[0] <= target <= nums[mid]`;

若 `mid` 位于右侧，需要判断是否有 `nums[mid] <= target <= nums[n - 1]`;

倘若要寻找旋转数组中的最小值又要如何解决。

[154. 寻找旋转排序数组中的最小值 II](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/description/) 的一种解法如下：

```c++
class Solution {
public:
    int findMin(vector<int>& nums) {
        int n = nums.size();
        int l = 0, r = n - 1;
        while (l < r) {
            int mid = (r + l) / 2; 
            if (nums[mid] < nums[r]) r = mid;
            else if (nums[mid] > nums[r]) l = mid + 1;
            else r--;
        }
        return nums[l];
    }
};
```
