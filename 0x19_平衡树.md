# 0x19 平衡树

## 引言

平衡树是结构较为平衡的二叉树。

在 c++ 中常使用 `set` 或 `multiset` 等容器作为平衡树。

## 例题

[532. 数组中的 k-diff 数对](https://leetcode.cn/problems/k-diff-pairs-in-an-array/description/)

```c++
class Solution {
public:
    int findPairs(vector<int>& nums, int k) {
        int ans = 0;
        int n = nums.size();
        sort(nums.begin(), nums.end());
        multiset<int> tree;
        unordered_set<int> st;
        for (int i = 0; i < n; i++) {
            int num = nums[i];
            auto it = tree.find(num - k);
            if (it != tree.end()) {
                if (st.count(num)) continue;
                st.insert(num);
                ans++;
            }
            tree.insert(num);
        } 
        return ans; 
    }
};
```
