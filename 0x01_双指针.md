# 0x01 双指针

## 引言

双指针是数组类题目的常用技巧，其表现形式为位于数组不同位置的两指针按照不同的规则线性移动。

## 例题

[283. 移动零](https://leetcode.cn/problems/move-zeroes/)

```c++
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int n = nums.size();
        int l = 0, r = 0;
        while (r < n) {
            if (nums[r] != 0) {
                swap(nums[r], nums[l]);
                l++;
            }
            r++;
        }
    }
};
```

[27. 移除元素](https://leetcode.cn/problems/remove-element/description/) 一题只是将非零元素延展为特定值的元素。

[26. 删除有序数组中的重复项](https://leetcode.cn/problems/remove-duplicates-from-sorted-array/description/) 一题则展示了双指针技巧如何运用于有序数组的去重：

```c++
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int n = nums.size();
        int l = 0;
        for (int r = 0; r < n; r++) {
            if (nums[l] != nums[r]) {
                l++;
                nums[l] = nums[r];
            }
        }
        return l + 1;
    }
};
```

[80. 删除有序数组中的重复项 II](https://leetcode.cn/problems/remove-duplicates-from-sorted-array-ii/description/) 一题是上一题的进阶版本，要求在去重过程中出现次数超过 2 次的数字在去重后仅出现 2 次:

```c++
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int n = nums.size();    
        int l = 0;
        int t = INT_MAX;
        for (int r = 0; r < n; r++) {
            if (nums[r] != nums[l]) {
                nums[++l] = nums[r];
            } else if (nums[r] == nums[l] && l != r && nums[r] != t) {
                nums[++l] = nums[r];
                t = nums[r];
            }
        }
        return l + 1;
    }
};
```

[15. 三数之和](https://leetcode.cn/problems/3sum/) 一题是双指针相关题目中不朽的经典：

```c++
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n = nums.size();
        vector<vector<int>> ans;
        if (n < 3) return ans;
        sort(nums.begin(), nums.end());
        for (int i = 0; i < n; i++) {
            if (i >= 1 && nums[i] == nums[i - 1]) continue;
            if (nums[i] > 0) break;
            int target = -nums[i];
            int l = i + 1, r = n - 1;
            while (l < r) {
               int sum = nums[l] + nums[r];
                if (sum < target) {
                    l++;
                } else if (sum > target) {
                    r--;
                } else {
                    ans.push_back({nums[i], nums[l], nums[r]});
                    while (l < r && nums[l] == nums[l + 1]) l++;
                    while (l < r && nums[r] == nums[r - 1]) r--;
                    l++;
                    r--;
                }
            }
        }
        return ans;
    }
};
```

[75. 颜色分类](https://leetcode.cn/problems/sort-colors/description/?envType=problem-list-v2&envId=2cktkvj) 一题需要在线性时间内解决「荷兰🇳🇱国旗问题」：

```c++
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int l = 0, r = n - 1;
        for (int i = 0; i <= r; i++) {
            while (i <= r && nums[i] == 2) {
                swap(nums[i], nums[r--]);
            }
            if (nums[i] == 0) {
                swap(nums[i], nums[l++]);
            }
        }
    }
};
```

通过观察不难发现，该解法借鉴了「移动零」中的思想。

[31. 下一个排列](https://leetcode.cn/problems/next-permutation/description/?envType=problem-list-v2&envId=2cktkvj) 中基于双指针可以实现线性时间内求下一个排列的算法：

```c++
class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            int j = n - 1;
            while (j >= 0 && nums[i] >= nums[j]) j--;
            swap(nums[i], nums[j]);
        }
        reverse(nums.begin() + i + 1, nums.end());
    }
};
```

该算法的设计十分巧妙，该算法的思路如下：

1. 逆向遍历找到第一个 `i` 满足 `a[i] < a[i + 1]`;
2. 逆向遍历找到第一个 `j` 满足 `a[i] < a[j]`;
3. `swap(a[i], a[j])`;
4. `reverse(a[i+1 : n])`

[11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/description/) 一题需要理解其中的贪心思想：

```c++
class Solution {
public:
    int maxArea(vector<int>& height) {
        int n = height.size();
        int l = 0, r = n - 1;
        int ans = 0;
        while (l < r) {
            int h = (min(height[l], height[r])) * (r - l);
            ans = max(ans, h);
            if (height[l] < height[r]) l++;
            else r--;
        }
        return ans;
    }
};
```

基于贪心思想，只有每次将高度更低的位置对应的指针进行收缩才有可能找到更大的容积。

至于如何运用双指针技巧接到[雨水](https://leetcode.cn/problems/trapping-rain-water/description/?envType=study-plan-v2&envId=top-100-liked)，需要细细品味...

```c++
class Solution {
public:
    int trap(vector<int>& height) {
        int ans = 0;
        int n = height.size();
        int l = 0, r = n - 1;
        int lmax = 0, rmax = 0;
        while (l < r) {
            lmax = max(lmax, height[l]);
            rmax = max(rmax, height[r]);
            if (height[l] < height[r]) {
                ans += lmax - height[l++];
            } else {
                ans += rmax - height[r--];
            }
        }
        return ans;
    }
};
```
